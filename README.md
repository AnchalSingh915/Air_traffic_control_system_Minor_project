# ✈️ Air Traffic Control System

## 📌 Project Overview
The **Air Traffic Control System** is a beginner-friendly Python GUI project developed to simulate airport and route management. It uses **Dijkstra’s Shortest Path Algorithm** to find the shortest route between two airports based on the distances provided by the user.

This project is developed for educational purposes to demonstrate graphical user interfaces, graph representation, and shortest-path algorithms.

## 🎯 Objectives
- To create a simple graphical interface for airport route management.
- To add airports and define routes with distances.
- To find the shortest path between two airports.
- To understand the practical implementation of Dijkstra’s algorithm.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **GUI Library:** Tkinter
- **Algorithm:** Dijkstra’s Shortest Path Algorithm
- **Visualization:** Tkinter Canvas
- **IDE:** Visual Studio Code

## ✨ Features
- Interactive graphical user interface.
- Airport and route management.
- Source and destination selection.
- Distance-based route calculation.
- Shortest-path identification.
- Graphical visualization of airports and connections.

## 🧠 Algorithm Used
Dijkstra’s algorithm calculates the shortest path between a source airport and a destination airport using the distances assigned to the routes.

**Example:**
- Delhi → Agra = 200 km
- Agra → Mumbai = 300 km
- Delhi → Mumbai = 700 km

**Shortest Route:** Delhi → Agra → Mumbai

**Total Distance:** 500 km
